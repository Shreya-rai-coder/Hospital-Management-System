# Hospital Management System

A GUI-based Hospital Management System developed using **Python, Tkinter, and SQL**. This application helps manage patient information, prescriptions, and medical records through an interactive desktop interface.

## Features

* Patient Information Management
* Prescription Generation
* Record Storage and Retrieval
* Update Existing Records
* Delete Records
* Clear Form Data
* User-Friendly GUI Interface
* SQL Database Integration

## Technologies Used

* Python
* Tkinter
* SQL
* MySQL Connector

```text
README.md
```

## How to Run

1. Install Python on your system.
2. Create the database using the `Table Hospital.sql` file.
3. Update the database credentials in `Hospital.py`.
4. Install required dependencies.
5. Run the application:

```bash
python Hospital.py
```
